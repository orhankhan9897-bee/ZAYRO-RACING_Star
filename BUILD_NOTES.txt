ZAYRO RACING — BUILD NOTES
- Preserved the existing 4.0 game systems and gameplay code.
- Added Daily Happiness Gift: 300–700 random credits once per local calendar day.
- Consecutive daily claims add +100 CR per streak day beyond day 1, capped at +500 bonus.
- Daily reward date/streak stored locally under dilseDailyGiftDate and dilseDailyGiftStreak.
- Removed the 4.1 suffix from the game name and corrected the header branding to ZAYRO RACING.
- Checks performed: JavaScript syntax, Python syntax, HTML parse/IDs, asset references, HTTP smoke test, ZIP integrity.
- Full interactive WebGL gameplay was not exhaustively tested.


- Added three driving profiles: PC keyboard/arrow keys, mobile touch buttons, and virtual steering wheel.
- Touch buttons and steering wheel modes both include on-screen accelerator, brake, reverse and nitro controls.
- Coarse-pointer/mobile devices default to touch buttons; the selected driving profile is saved locally.
- PC users retain keyboard/arrow controls and can optionally select either touch mode.


ULTRA GRAPHICS UPGRADE
- Improved WebGL lighting with directional light, sky fill and subtle rim lighting.
- Added metallic clear-coat highlights and view-angle Fresnel reflections to car paint and trim.
- Enhanced asphalt micro-texture, road sheen and wet-road reflections in rain.
- Refined headlight falloff and atmospheric fog distance for stronger depth.
- Ultra preset now uses a sharper render scale; adaptive scaling remains enabled to help maintain performance.
- Select GRAPHICS QUALITY -> ULTRA in the garage for the highest-quality render setting.
- These are stylized real-time WebGL effects, not a full ray-traced renderer; performance depends on the device/browser.
