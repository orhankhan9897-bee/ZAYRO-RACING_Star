# ZAYRO RACING — Created by Rihan

A browser-based WebGL racing game. This release keeps the existing ZAYRO RACING gameplay and adds the Champion Rewards certificate system.

## Champion Rewards update
- After a stage is completed, download a personalized A4 landscape PDF certificate with player name, stage name, Gold World Cup trophy, founder Rihan, date/time and unique certificate ID.
- Certificate download works locally in modern PC and mobile browsers; no external PDF library is required.
- Certificate records are stored locally by player name and stage.
- Updated visible game branding to ZAYRO RACING.

## Start the game (Windows)
1. Extract the ZIP.
2. Open the `ZAYRO_RACING` folder.
3. Double-click `Start ZAYRO RACING.bat`.
4. Keep the terminal window open while playing.

Requires a modern browser with WebGL (Chrome or Edge recommended). Progress is stored locally in the browser.


## Driver save backup
- Export your career, credits, upgrades, cars, settings and daily-gift streak from the garage.
- Import that JSON save on another browser or PC to continue your profile.
- Import replaces the current local game save after confirmation. Keep the exported JSON somewhere safe.

## Personal best ghost racer
- Race against the fastest saved run for each stage and event.
- A cyan ghost car replays the best racing line, and the timer panel shows whether you are ahead or behind.
- Ghost runs save locally and are included in exported driver backups.


## Mobile controls update
- **Keyboard / Arrow Keys**: for PC keyboard play.
- **Touch Buttons**: on-screen left/right, gas, brake, reverse and nitro buttons.
- **Touch Steering**: virtual steering wheel plus on-screen pedals.
- Phones default to Touch Buttons on first visit. Select another profile in the garage at any time; the choice is saved in that browser.

For QR-code play, the QR code must point to a URL your phone can access (such as a deployed HTTPS site or your PC's LAN IP). `127.0.0.1`/`localhost` only opens the game on the same device.


## Ultra graphics upgrade
The renderer now includes richer directional/ambient lighting, metallic clear-coat highlights, Fresnel edge reflections, more detailed asphalt variation, stronger wet-road sheen in rain, refined headlights and atmospheric depth. In the garage, choose **GRAPHICS QUALITY → ULTRA** for the sharpest rendering. If the game becomes slow on a phone or older PC, choose **BALANCED** or **PERFORMANCE**. These are real-time WebGL visual effects and are not ray tracing.

# ZAYRO RACING v6.0 — Online Multiplayer · Position Certificates · Winner Rewards

Everything above still works exactly as before. v6.0 only *adds* modules (`zayro_results.js`, `zayro_rewards.js/.css`, `zayro_mp.js/.css`, `zayro_mp_config.js`, `multiplayer-server/`) and small additive hooks. `game.js`, `style.css` and all graphics/cockpit/mobile files are byte-identical to the previous release.

## 1. Online multiplayer
**Play locally (two browser tabs / two devices on the same Wi-Fi)**
1. Install Node.js 18+ (no `npm install` needed — the server has zero dependencies).
2. Start the server: double-click `Start_ZAYRO_MULTIPLAYER_SERVER.bat` (or `cd multiplayer-server && node server.js`). It listens on port 8787.
3. Start the game as usual (`Start_ZAYRO_RACING.bat` / `python run_server.py`) and open it.
4. On the garage screen press **🌐 ONLINE** (top-right). Player 1: **CREATE PRIVATE ROOM** → share the 5-letter code. Player 2: type the code → **JOIN**. Both press **I AM READY**; the host presses **START RACE** (host also chooses stage / event / road).
   On a phone use your PC's LAN address in the SERVER box, e.g. `ws://192.168.1.20:8787`.

**Deploy for the internet (game stays on GitHub Pages)**
1. GitHub Pages hosts only the static game (no change needed). The multiplayer server must run on a Node host (Render, Railway, Fly.io, a VPS…). With Render: New → Blueprint → select this repo; `multiplayer-server/render.yaml` is included.
2. Set environment variables on the host (never in the game files):
   - `SERVER_SECRET` – long random string; signs race results. Stays on the server only.
   - `ALLOWED_ORIGINS` – your site, e.g. `https://YOURNAME.github.io` (blocks other websites from using your server).
   - `TRUST_PROXY=1`, optional `MAX_PLAYERS` (2–4).
3. Put the public address in `zayro_mp_config.js`: `window.ZAYRO_MP_CONFIG={server:'wss://your-server.onrender.com'}` (an address is not a secret). The host provides TLS, so players connect with `wss://`. A page served over https refuses non-secure `ws://` automatically.

**How it works.** The server is authoritative for rooms, readiness, the countdown (shared seed, so everyone gets the same traffic layout), position plausibility (impossible jumps are clamped), finish validation, and the final ranking. Clients stream their car at 20 Hz; opponents are drawn as real cars from 15 Hz server snapshots. Disconnects: the seat is kept for 30 s and the same tab reconnects automatically with a private session token; a player who does not finish is a DNF. Capacity is configurable to 4 players (server tested with 4; the 2-player flow is what was tested end-to-end in browsers). No car-to-car collisions in v1.

> Note on Socket.IO: the brief said "such as Node.js and Socket.IO". The server uses a small built-in RFC 6455 WebSocket implementation instead (no `npm install`, nothing to break on Windows). If you prefer Socket.IO, the message protocol in `multiplayer-server/lib/rooms.js` is transport-independent.

## 2. Position-based certificates
- The finishing position is computed automatically: single-player = your real position against the 3 AI rivals; online = the server-decided position (certificate waits for the server result; if the server never confirms, no certificate is issued).
- PDF shows **1ST / 2ND / 3RD / 4TH … PLACE**, player name, stage, race date, completion time, finish speed, medal and certificate ID (server-verified races also carry the server signature).
- Eliminated (crashed out) players and players who leave an online race get **no** certificate and **no** rewards. Solo time trials (no rivals) get a "Time Trial · Solo Run" certificate without a place.
- Download buttons are in the existing finish screen (dark collector + light print-friendly editions).

## 3. Winner rewards & unlocks
- A **Victory Rewards** screen (animated place number, counting coins, rewards revealed one by one, confetti, fanfare; respects "reduce motion") opens after every finished race.
- Rewards scale with finishing position (1st > 2nd > 3rd > 4th+), stage (1–5), event, difficulty, online bonus and performance (clean race, par time, near misses).
- Unlocks: Phantom GT (win Stage 3), Solar Titan (win Stage 4), Stratos Zero (win Stage 5 on PRO/LEGEND), nitro/premium upgrades (applied to the existing garage upgrades), trophies (gold/silver/bronze per stage), 6 exclusive paint skins (appear in CUSTOM PAINT), 10 racing achievements, driver XP.
- Each race result is claimed **once** (unique id; also blocked across tabs/reloads). Everything is saved in localStorage (`zayroRewards` + the existing credits/upgrade/car keys) and included in driver-save export/import. The garage has a new **Winner's Cabinet**.
